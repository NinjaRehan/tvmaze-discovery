## Manual acceptance checklist

Use a real Android device or emulator with network access. Browser equivalents of the core feature checks passed the recorded audit; these unchecked items track the separate Android device acceptance pass:

- [ ] Launch the app; inspect posters, titles, genres, and ratings.
- [ ] Scroll far enough to fetch a second page; confirm new shows appear.
- [ ] Pull to refresh and verify the collection reloads.
- [ ] Search quickly and confirm only the most recent query is displayed.
- [ ] Clear a search while its request is in flight; confirm no old results return.
- [ ] Search for a long nonsense title and inspect the no-results state.
- [ ] Open a show; inspect summary, rating, genres, status, network, and language.
- [ ] Switch seasons and inspect episode ordering and episode summaries.
- [ ] Open the cast tab and inspect actor and character information.
- [ ] Add a show; confirm its saved state agrees across screens.
- [ ] Force-stop and relaunch the app; confirm the saved show remains.
- [ ] Disconnect the network and inspect saved metadata and graceful image fallbacks.
- [ ] Remove a saved show; inspect the empty-watchlist state.
- [ ] Disconnect the network during initial discovery, search, and pagination; inspect retries.
- [ ] Reconnect and verify retry recovers the relevant feature.
- [ ] Check a small screen, keyboard appearance, scrolling, and Android back navigation.
- [ ] Capture all seven runtime screenshots and update the README gallery.
- [ ] Push to GitHub; confirm the CI workflow succeeds and APK artifact is available.
- [ ] Review the source and explain each BLoC without relying on a memorized script.
